Lithography queue tool

How long lots wait at one group of lithography steppers, using SMT2020 benchmark fab data and the Sakasegawa approximation for parallel tools (G/G/m).

Module 1 build: tool group Litho_FE_98 from the SMT2020 data. Cost assumptions are still placeholders. Edit inputs in js/app.js.
